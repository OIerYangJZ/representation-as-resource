# MR25 matched-representation campaign

`matched_cells.jsonl` is the frozen 525-cell matrix generated by
`scripts/run_matched_representation_benchmark.py`.  Fifteen balanced design
points vary `m`, dispersal `r`, alphabet size `K`, support density, and five
seeds.  Every target is crossed with seven representations and five compilers.

Each worker uses the same `{cx,rz,h}` target basis, zero target error, 30 s
timeout, 2 GiB RSS cap, and certificate policy.  `completed` requires a passed
certificate.  `certificate_unsupported` remains a status and is excluded from
numeric means.

`matched_summary.csv` contains completion and mean metric 95% intervals by
representation/compiler. `factor_summary.csv` conditions on every sampled
factor. `campaign_manifest.json` freezes codecs, bridges, versions, limits, and
certificate rules.  The PDF and TeX fragment are generated views, not hand
edited data.
