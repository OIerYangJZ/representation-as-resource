# E8 Preregistration — the commitment toll: what the committed channel pays that the state channel does not

Date: 2026-08-08.  **This file is committed before any E8 experiment run; the
git commit order is the timestamp.**  Motivated by the 0808 review note
(`PaperDraft/0808comment.md`, sections VI and IX, item P1-2), which observed
that the two payment channels of `thm:w1-unified-frontier` exchange at
roughly 6:1 rather than 1:1 in `fig:eta-sweep`, and conjectured that the rate
is *determined by address width*.

## What is under test, and how it differs from the motivating conjecture

The frontier

  Abar_p + (2p-1) S >= (1-delta) m log2 K - h2(delta)

charges committed output and crossing state **at par**.  The measured device
of `fig:eta-sweep` pays about 16 bits per dispersed generator in the
committed channel and about 2.59 bits in the state channel.  The review note
proposes that this 6:1 rate is set by the width of the public address a
committed record must carry.

**We predict that conjecture is wrong, and that the true asymmetry is
smaller and has a different origin.**  Decomposition under test:

  committed bits/generator  =  payload  +  identity  +  codec slack
  state bits/generator      =  payload

- *payload* = log2 Q + 1 = 2.585 bits (residue trit + sign), common to both.
- *identity* = the information saying **which** generators were committed
  early.  A compiler that defers pays none of it: the round-2 records
  disclose the mask for free.  A compiler that commits early must
  self-identify **if committed records are immediately executable**, i.e. if
  there is no going back to reinterpret an emitted instruction once the
  suffix arrives.  That is the operating assumption already declared in
  `rem:streaming-grounding` (append-only first exposure, real-time control
  stack).  Its size is the entropy of the commitment schedule,
  log2 C(m,k) bits over k committed generators, **not** the address width.
- *codec slack* = everything the particular serializer wastes.  The varint
  address-per-record encoder of `run_eta_sweep.py` spends 8*ceil(varint) bits
  where the information content is far less.

If this decomposition is right, then: (i) most of the observed 6:1 is codec
slack, not a law; (ii) the irreducible toll is 0 at eta = 1 and grows only
as h2(eta)/eta as commitment becomes sparse; (iii) the toll disappears
entirely if self-identification is dropped.  Each is separately falsifiable
below.

## Frozen design

### Arm A — own device (`scripts/run_commit_toll.py`)

Device: the two-round masked-share device of `run_eta_sweep.py`, unchanged
(Q = 3, binary aggregates x_j, tracked signs, dispersal mask Bernoulli(eta)).
Instances are generated by the same construction with seed string
`e8-{m}-{eta}-{seed}`.

Four encoders, **each restart-verified in every cell** (the serialized
snapshot alone, plus the round-2 record suffix, must reproduce the exact
correct output; no live Python object counts as state):

- `deferred` — compact output, pays at the cut in STATE: packed trits +
  sign bits, positions implicit in the public round-2 order.
- `stream_varint` — the existing streaming encoder: `varint(j)` + one
  payload byte per committed generator.
- `stream_opt_selfid` — identity-optimal self-identifying streaming
  encoder: the committed mask is encoded by its exact combinadic rank in
  ceil(log2 C(m,k)) bits, followed by base-3 packed residues and packed
  sign bits.  The prefix is parseable on its own.
- `stream_opt_maskdeferred` — control: identical payload packing, but the
  mask is **not** in the prefix; it is recovered from the round-2 suffix.
  The prefix is not independently parseable.  This arm exists to isolate
  self-identification as the operative assumption.

Scan: m in {128, 512, 2048} for all four encoders (combinadic ranking is
exact and decodable at this size); m in {128, 512, 2048, 8192, 32768} for
`deferred` and `stream_varint` only.  eta in {0.125, 0.25, 0.5, 1.0}.
Seeds {1, 2, 3}.

Primary metric: **bits per dispersed generator**, defined as
8 * (encoder byte length - fixed header bytes) / k where k is the realized
number of dispersed generators in that instance, with k >= 16 required for a
cell to enter the analysis (below that the header dominates).

### Arm B — third-party portability (`scripts/run_address_width_check.py`)

Fixed rotation content, varying address width.  For rotation count
m = 64 placed on the first 64 qubits of an n-qubit register,
n in {64, 512, 4096, 65536}, emit the committed serialization from tools the
authors do not control: Qiskit 2.4.0 (`qasm3.dumps`) and pytket 2.16.0
(`circuit_to_qasm_str`, and `Circuit.to_dict()` JSON).  Angles, gate count,
and gate order are byte-identical across n by construction; only the address
text changes.  Metric: serialized bytes per rotation record.

## Preregistered predictions

- **C1 (calibration, not a test)**: `stream_varint` committed bits per
  generator equals 8 * (mean_j varint_len(j) + 1) within 2%, i.e.
  16.00 / 22.00 / 23.50 / 23.88 / 27.97 bits at m = 128 / 512 / 2048 /
  8192 / 32768.  Recorded to show the codec is behaving as specified; it is
  arithmetic, not evidence.

- **P1 (primary — the toll is schedule entropy, not address width)**: for
  every cell with k >= 16,

    bits/gen(`stream_opt_selfid`) - bits/gen(`deferred`)

  equals log2 C(m,k) / k within 5%.  In particular it is **independent of m
  at fixed eta**, which address width is not.

- **P2 (primary — par pricing is tight when the schedule is public)**: at
  eta = 1.0 the same difference is <= 0.2 bits per generator at every m.

- **P3 (mechanism control — self-identification is what buys the
  asymmetry)**: for `stream_opt_maskdeferred` the same difference is
  <= 0.2 bits per generator at **every** eta, not only at eta = 1.

- **P4 (refutation of the motivating conjecture, stated in advance)**: the
  toll of P1 does not grow with address width.  Concretely, at eta = 0.5 the
  measured toll changes by less than 0.2 bits between m = 128 and m = 2048,
  while `stream_varint` over the same range changes by more than 7 bits per
  generator.  The 6:1 rate of `fig:eta-sweep` is therefore attributed to
  codec slack, and no address-width law is claimed.

- **P5 (third-party portability, weak check)**: in Arm B, serialized bytes
  per rotation is monotone nondecreasing in n for every tool, and increases
  by at least 3 bytes per rotation from n = 64 to n = 65536.  This is a
  check that real toolchains do pay address width in committed output; it is
  explicitly *not* the mechanism of P1 and does not support it.

## Decision rule (frozen)

- **P1 AND P2 AND P3** -> the asymmetry is established with its mechanism:
  the frontier's par pricing is tight exactly when the commitment schedule
  is public, and otherwise the committed channel additionally pays
  log2 C(m,k) bits that the state channel never pays.  A proposition to this
  effect is drafted for the paper, `fig:eta-sweep`'s 6:1 is reported as
  decomposed (toll + slack), and the ES-level sentence is licensed.
- **NOT P2** -> the mechanism is wrong (a toll that survives a public
  schedule is not schedule entropy).  No new claim; report as-is.
- **NOT P3** -> self-identification is not the operative assumption; the
  asymmetry claim reverts entirely and `fig:eta-sweep` keeps only its
  descriptive observation.
- **P2 AND P3 AND NOT P1** -> the toll exists and is bought by
  self-identification, but is not equal to schedule entropy.  Report the
  measured relation as-is; do **not** name a law; no proposition drafted.
- **NOT P5** -> Arm B is reported as a negative portability check; it does
  not affect P1-P3, which stand or fall on Arm A alone.

No post-hoc metric substitution.  If a cell fails restart verification the
run aborts rather than reporting the cell.

## Amendment 1 (2026-08-08, before any experiment run)

Committed as a separate commit, still ahead of every run; no data has been
observed at the time of writing.  Two specifications were underdetermined in
the text above and would have made P1 fail on a quantization artifact rather
than on nature:

1. **Encoder spec made explicit.**  The bit-packed encoders (`deferred`,
   `stream_opt_selfid`, `stream_opt_maskdeferred`) concatenate their fields
   into a single integer with exact alphabet sizes -- mask rank in C(m,k),
   residues in 3^k, signs in 2^k -- and round to whole bytes **once**, at the
   end.  Field-by-field byte rounding is not used.  Body bit length is
   therefore ceil(log2(C(m,k) * 3^k * 2^k)) for `stream_opt_selfid` and
   ceil(log2(3^k * 2^k)) for the other two.
2. **Header made identical across all four encoders** (MAGIC + varint(m) +
   varint(k)), so that the header subtraction in the metric cannot favour
   any arm.
3. **P1 tolerance**: "within 5%" is amended to "within 5% **or** within 0.5
   bits per generator, whichever is larger".  At the smallest admissible
   cell (m = 128, eta = 0.125, k ~ 16) a single byte of final rounding is
   0.5 bits per generator, which is 12% of the predicted toll; without this
   allowance P1 would test the rounding rule rather than the mechanism.
   Both the byte-granular metric (as originally specified, and matching the
   paper's file-size accounting) and the bit-exact body length are recorded
   in every cell, and both are reported.

No prediction, arm, scan range, or decision rule is changed.
