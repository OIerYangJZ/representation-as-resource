# Overleaf upload bundle — Quantum submission

Generated by `PaperDraft/scripts/make_overleaf_bundle.sh`. Re-run that script
after editing the manuscript; do not hand-edit this directory.  This bundle is
the **Quantum submission version**: the two classical-text passages in the
working tree's acknowledgements are intentionally excluded.

## Uploading

Overleaf → **New Project → Upload Project** → `overleaf_bundle.zip`.
The archive stores its files at the archive root, so `main.tex` lands at the
project root and Overleaf selects it as the main document automatically.

Compiler: **pdfLaTeX** (`quantumarticle`). No custom class or style file is
needed — `quantumarticle` and its `quantum.bst` bibliography style ship with
Overleaf's TeX Live.

## Two documents in one project

| Document | File | Pages |
|---|---|---|
| Manuscript | `main.tex` | 53 |
| Cover letter | `cover_letter/cover-letter.tex` | 2 |

Overleaf compiles one document at a time. To build the cover letter, right-click
`cover_letter/cover-letter.tex` in the file tree and choose **Set as Main File**;
switch back to `main.tex` for the manuscript. A pre-built `cover-letter.pdf` is
included, so this is only needed if you edit the letter.

## Layout

```
main.tex                  manuscript (quantumarticle, a4paper/twocolumn/10pt)
manuscript.tex            shared manuscript body
references.bib            bibliography source
main.bbl                  pre-built bibliography (quantum.bst), resolves on pass 1
appendix/                 appendix_A, appendix_B, appendix_C_prxq
theory/                   the six \input theory packages
generated/                pipeline-generated numbers and tables
research/                 generated table rows cited by the appendices
figures/                  all figures referenced by main.tex
cover_letter/             cover letter source + compiled PDF
```

## Difference from the working tree

In the repository, the shared manuscript body `main.tex` reaches outside
`PaperDraft/` for two prefixes:

- `\input{../theory/...}` → rewritten to `theory/...`
- `\includegraphics{../figures/...}` → rewritten to `figures/...`

Overleaf has no parent directory above the project root, so the build script
copies that body as `manuscript.tex`, rewrites the two prefixes, and installs
the Quantum wrapper as the archive-root `main.tex`.

Note that `eta_sweep_pareto.pdf` exists in both source figure directories with
different content. The shared manuscript cites the `PaperDraft/figures/` copy, and that is
the one carried into `figures/` here.
